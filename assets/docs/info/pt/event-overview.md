Um evento de coleta registra um esforço de amostragem definido em um local e em um momento. Os espécimes se vinculam a um evento para obter seu local, suas datas, seu contexto de amostragem e sua equipe de campo, de modo que muitos registros de espécimes podem compartilhar um mesmo evento.

O NAHPU monta o Event ID a partir do Site ID e da data de início. Acrescente um sufixo apenas quando outro evento teria o mesmo identificador.

Como você cria um evento depende do protocolo de amostragem e de você acompanhar ou não os dados ambientais. Por exemplo, se você amostra vários dias no mesmo local com o mesmo protocolo e não registra dados ambientais, pode manter o mesmo evento para todos os dias. Ainda assim, recomendamos criar um evento novo pelo menos uma vez por dia para acompanhar os dados ambientais e as possíveis mudanças na equipe de campo e nos equipamentos, e para que o evento seja registrado de forma consistente. O botão `Duplicate`, no canto superior direito, pode ser usado para criar um evento novo com a mesma configuração de um evento existente.
