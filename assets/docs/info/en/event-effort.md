Effort records describe how sampling was carried out. Add each method separately and record the number of units, the brand and model of the equipment, its size or dimensions, and notes. Include the units in the size values (e.g. "10 cm × 10 cm × 10 cm").

Use the same units and controlled method names throughout the project so efforts can be compared. State enough context for another person to understand the effort without inferring missing details. Duplicating an event copies its effort records.

Review copied equipment counts and methods for each event. Record zero only when it is an observed count, and explain incomplete effort in the notes.
