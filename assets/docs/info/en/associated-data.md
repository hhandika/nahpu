Associated data connects a record to supporting links and non-media files, such as accession references, datasets, permits, protocols, sequence records, or documents.

Choose `Link` or `File` in `Data type`, add a name, description, and date, and provide a stable URI or a managed file. Use Media instead for images, audio, and video so audiovisual metadata is recorded consistently. Verify every link or file after adding it.

A URI references an external resource; it does not make that resource available offline. Open a managed file after import and include it in your backup verification.

On desktop, `Copy to project` stores a managed copy; `Link original` depends on the source path remaining accessible. Confirm file availability after a transfer.
