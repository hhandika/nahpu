A project groups the sites, collecting events, specimens, personnel, taxa, narratives, and supporting files for one body of work. Use `Edit` to update project information. Set the project time zone to describe the recorded local times; changing it does not convert existing date and time values.

The project UUID identifies the project across devices. `Export info` and `Show QR` share its identity and metadata, without records or media. The UUID is separate from the project catalog number used in specimen Field IDs.

For a daily field backup, use `Export project` and keep a copy off the working device. ZIP and TAR.GZ include available media; light JSON.GZ contains records without media. Review missing-file warnings. Use home-screen `Import project` on a receiving installation, or `Merge project` within an existing project. Create a database backup before importing, merging, or replacing installation data.
