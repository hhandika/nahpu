Los datos asociados conectan un registro con enlaces y archivos no multimedia de apoyo, como referencias de accesión, conjuntos de datos, permisos, protocolos, registros de secuencias o documentos.

Elija el tipo de dato que describa la relación, agregue un nombre, una descripción y una fecha, y proporcione un URI estable o un archivo gestionado. Use Media para imágenes, audio y video, de modo que los metadatos audiovisuales se registren de forma consistente. Verifique cada enlace o archivo después de agregarlo.
