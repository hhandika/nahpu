Kolom cuaca menjelaskan kondisi yang teramati selama kegiatan pengumpulan, termasuk suhu dan kelembapan udara, tutupan awan, serta curah hujan. Anda dapat memilih kolom yang tampil pada data lingkungan melalui pengaturan kegiatan.

Jangan menyalin cuaca antarkegiatan kecuali pengukurannya memang berlaku untuk keduanya.
